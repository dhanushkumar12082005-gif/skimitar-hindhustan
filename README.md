# Skimitar Hindhustan - Industrial Solutions & Career Training Website

A modern, responsive, and beautifully designed website for **Skimitar Hindhustan**, a leading provider of industrial solutions and professional career training programs.

## 🚀 Features

### ✨ Design Highlights
- **Modern UI/UX** - Clean and professional design with attractive color schemes
- **Responsive Design** - Fully responsive on desktop, tablet, and mobile devices
- **Smooth Animations** - Engaging animations and transitions throughout the site
- **Interactive Elements** - Hover effects, smooth scrolling, and dynamic interactions

### 📄 Sections Included
1. **Navigation Bar** - Sticky navigation with smooth scrolling
2. **Hero Section** - Eye-catching hero with animated background shapes
3. **About Us** - Company information with statistics cards
4. **Services** - 6 service offerings with hover effects
5. **Courses** - Featured training courses with enrollment buttons
6. **Contact** - Contact information and message form
7. **Footer** - Complete footer with social links

### 🎨 Design Features
- Gradient backgrounds and overlays
- Floating animations
- Hover transformations
- Color-coded icons from Font Awesome
- Responsive grid layouts
- Shadow and depth effects

## 🛠️ Technology Stack
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with gradients, animations, and flexbox/grid
- **JavaScript** - Interactive functionality
- **Font Awesome** - Icon library

## 🚀 Getting Started

### Installation
1. Clone the repository
```bash
git clone https://github.com/dhanushkumar12082005-gif/skimitar-hindhustan.git
```

2. Navigate to the directory
```bash
cd skimitar-hindhustan
```

3. Open in browser
```bash
open index.html
```

Or use a live server for better experience:
- VS Code: Install "Live Server" extension and right-click → "Open with Live Server"
- Python: `python -m http.server 8000`
- Node: `npx http-server`

## 🎓 Customization Guide

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1e40af;
    --secondary-color: #f59e0b;
    --accent-color: #10b981;
    /* ... more colors ... */
}
```

### Update Content
1. **Company Name**: Edit logo in HTML
2. **Services**: Modify service cards in the services section
3. **Courses**: Update course details in the courses section
4. **Contact Info**: Update contact information in the contact section

### Add New Sections
1. Add HTML in `index.html`
2. Add CSS styling in `styles.css`
3. Add JavaScript functionality in `script.js`
